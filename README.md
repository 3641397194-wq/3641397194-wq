## 快速开始

```powershell
git clone https://github.com/3641397194-wq/gpt6-Astra.git
cd gpt6-Astra
python coldbrew.py --activate 冷咖啡 --profile MAX --prompt "把这段需求拆成可执行步骤"
```

桌面版位于 `desktop/`，完整主页位于 `docs/index.html`。所有输入都由运行者明确传入。
