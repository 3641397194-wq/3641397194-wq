## 现在做什么

我在做 ColdBrew Zero：一套从零原创的提示词工作台，把目标锁定、上下文整理、输出生成和检查回看压进一条清晰链路。

- 品牌启动词：`冷咖啡`
- 工作控制词：`BREAK//OPEN`
- 工作方式：`OBJECTIVE -> CONTEXT -> OUTPUT -> CHECK`
- 交付形态：Python CLI + Electron 桌面版
